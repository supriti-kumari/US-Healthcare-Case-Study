# US Healthcare Case Study

## Project Overview
This project focuses on analysing US healthcare data to understand patient demographics, healthcare billing patterns, and hospital resource management.

The case study was completed as part of a guided classroom project during the Coding Ninjas Job Bootcamp.

## Objectives

The analysis focuses on three key areas:

### 1. Demographic Analysis
- Identify common medical conditions across different demographic groups.
- Analyse patterns based on age, gender, and blood groups.

### 2. Patient Bill Optimization
- Compare average billing amounts across different medical conditions.
- Analyse billing patterns based on admission types and medications.
- Identify potential ways patients can manage healthcare expenses.

### 3. Hospital Resource Management
- Analyse admission patterns over time.
- Examine admission trends across different days and categories.
- Identify opportunities for better hospital resource planning.

## Tools & Skills Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Data Analysis
- Charts and Visualisation
- Basic Statistical Analysis

## Project Workbook

The Excel workbook includes:
- Original Raw Data

- Billing Analysis

- Project Insights and Recommendations

## Learning Outcome

This project provided practical exposure to working with healthcare datasets, cleaning data, analysing trends, creating Pivot Tables, and presenting findings through Excel.
